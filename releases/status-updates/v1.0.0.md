# FitDex v1.0.0

## First Public Release

FitDex v1.0.0 is the first public Android release of the local-first retro RPG fitness tracker.

## Highlights

- Build reusable workout routines, log sets, track active training time, and use independent rest timers.
- Browse 804 exercises with instructions, muscle targets, and on-demand Android demonstration media.
- Log meals, nutrition targets, progress, personal records, journal entries, achievements, and RPG progression.
- Keep fitness data on device with local storage, portable `.fitdex` backup and restore, and no account requirement.
- Choose Spartan or Amazonian themes with light, dark, and system brightness modes.

## Android

- Native splash, cold-start boot sequence, non-blocking update checks, and adaptive faction launcher branding.
- Exercise MP4 files are excluded from the APK; Android fetches demonstrations only when requested.

## Notes

- This direct-download APK is signed for Android installation outside Google Play.
- Back up local data before moving to another device.
