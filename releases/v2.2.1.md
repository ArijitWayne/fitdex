# FitDex v2.2.1

FitDex v2.2.1 combines the interface and exercise-media improvements from v2.2.0 with corrected Android release discovery and explicit release approval. It replaces the unsuccessful v2.2.0 release.

## What's New
- Application-wide UI modernization brings cohesive shells, compact panels, clearer visual hierarchy and consistent controls across FitDex.

## Improvements
- Weekly Plan presentation and navigation make planned training easier to scan and manage.
- Workout completion and history views present completed sessions and results more clearly.
- Achievement presentation improves grouping, readability and progression feedback.
- Dialogs and navigation use consistent spacing, controls and interaction states.
- FitDexInfo and in-app changelogs show explicitly approved successful releases. Failed, superseded and unapproved releases are excluded from promotion.
- The updater selects an approved release only when its official APK, SHA-256 and Android versionCode are valid.

## Fixes
- Fixed GitHub release discovery in Android WebView by removing a CORS-blocked request header.
- Update checks distinguish network failures, timeouts, HTTP failures, rate limiting and malformed release metadata. Failed checks no longer cache an error as a successful result.
- FitDexInfo refreshes release discovery when connectivity returns or the tab becomes visible. Failed requests cannot silently promote stale stored release data.
- Fixed exercise video URL compatibility in web and installed PWA builds while preserving native Android media handling.
